# METEOR 組み込み向け性能分析・最適化プラン (r37完走後に実施)

目的: NVIDIA Orin / R-Car Gen5 実装に向け、レイテンシ×精度のパレートを
実測で埋める。各構成は「アブレーションエンジン方式」= 実際にONNX/TRTエンジン
を作り、同一ベンチ(deploy/bench_engine.py)+同一val評価で直接比較する。

## 計測マトリクス (各構成: エンジンms/FPS + val mIoU / veh P/R / vru R / ADEc)

| # | 構成 | 期待削減 | 再学習 | 備考 |
|---|---|---|---|---|
| 0 | ベースライン v42 (r37) 8cam fp16 | - | - | 基準 |
| 1 | 7カメラ (BACK_NARROW削除) | ~-12% | 不要(要精度確認) | 後方遠距離のみ影響 |
| 2 | 組込ヘッドセット (LG/2Ddet/2Dseg/flow除去) | ~-6ms | 不要 | エクスポータで出力絞り |
| 3 | refiner無し | ~-2ms | 不要 | 精度差も計測 |
| 4 | INT8 PTQ (E2Eヘッドはfp16維持) | fp16比 1.3-1.8x | 不要(劣化時QAT) | エントロピーキャリブ~500実フレーム |
| 5 | **非対称BEVグリッド: 前方80m/後方40m (800→600行, -25%)** | BEVブロック~-25% (~-10ms) | 要 (v43/v44) | 前方検知距離を犠牲にしない。GTは既存800行の前方600行クロップで流用可。後方はBACK_WIDEの実用域(~40m)に整合 → #1(後方NARROW削除)とセットで実施 |
| 6 | チャンネルプルーニング 幅2/3 (BEVリング96→64ch, tf 256→192) | BEVブロック-30〜45% | 要 (L1選択+fine-tune) | リング153MB→2/3の副次効果。INT8と乗算的 |
| 7 | (参考) 対称縮小 640×400 | -35% | 要 | 範囲維持なら0.25m/セル化=遠方小物体に不利。**優先度低(最後の手段)** |

実施順: #1-#3 (再学習不要、即日) → #4 INT8 → #5 非対称グリッド+#1セット (v43) →
#6 プルーニング (最終)。組み合わせ最終形の目標: Orinでリアルタイム(5Hz)+never-degrade。

## ゲート (never-degrade)
- BEV mIoU ≥ ベースライン-0.005 / veh R ≥ -0.01 / vru R ≥ -0.01 / ADEc ≥ -0.02m
- 遠方帯 (40m+) の veh/vru recall を別途記録 (非対称グリッドの後方影響は
  後方40m内のrecallで確認)

## 非対称グリッドの実装メモ (v43/v44)
- row r: x = 80 - 0.2r。前方600行 = x∈[-40, 80] → 既存GT(800行)の r∈[0,600) クロップで再利用可
- BEV_H=600, det grid 300×250, streaming ring [3,96,600,500] (I/O形状変更 = エンジン互換切れ)
- ego位置が中心からずれる → make_warp_theta / bev_rotation_aug / demo描画の中心定数を要修正
